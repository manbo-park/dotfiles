# 작업 흐름 제어

## 작업 단위
- 특별한 추가 지시사항이 없는 한, 작업은 **커밋 단위**로 진행한다.
- 하나의 커밋 단위는 기능 단위가 아닌 **작은 논리적 작업 단위**로 나눈다. 하나의 커밋에는 의미 있는 하나의 변경 사항(기능 추가, 버그 수정, 리팩토링 등)만 포함한다.

## 커밋 단위 중단 규칙 (필수)
- 한 커밋 단위의 코드 변경이 완료되면 **반드시 멈추고** 작업 내용을 요약·보고한다.
- 보고 후 사용자의 명시적 승인이 있어야 다음 커밋 단위로 진행할 수 있다.
- "진행해", "계속", "다음" 등의 지시는 **다음 한 커밋 단위만** 진행하라는 의미로 해석한다.
- 여러 커밋을 한 번에 진행하려면 사용자가 "나머지 전부 진행해", "끝까지 진행해" 등 **명시적으로 일괄 진행을 요청**해야 한다.

## 커밋 생성 규칙
- 코드 변경 후 자동으로 커밋하지 않으며, "커밋해", "커밋해줘", "커밋 작성해" 등 명시적 요청이 있을 때만 커밋한다.
